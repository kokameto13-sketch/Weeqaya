# Weeqaya Final Project

مشروع Android Studio عربي لتطبيق متابعة أعمال الصيانة.

يشمل الواجهة الأساسية، بيانات الصيانة، قبل/بعد، التصوير، البحث، وشاشة Drive.

ملاحظة مهمة: ملف APK النهائي لا يمكن ادعاء أنه مبني من هذه الجلسة بدون Android SDK/Gradle build فعلي. كما أن ربط Google Drive المركزي يحتاج إعداد OAuth في Google Cloud؛ لا توجد كلمات مرور أو Tokens داخل المشروع.

للبناء: افتح المشروع في Android Studio ثم Build > Generate APKs.
